# Location of different water points in Cap Haitien, Haiti

This data includes water point data from the mWater platform. Water
points are for the city Cap Haitien, Haiti in 2022. The data collection
and characterization was done between 2015 and 2022.

## Usage

``` r
mwater
```

## Format

A tibble with 1849 rows and 7 variables:

- latitude:

  Lattitude coordinate

- longitude:

  Longitude coordinate

- administra:

  Communal section- smallest administrative unit in Haiti

- type:

  Type of water access point

- date_added:

  Date water access point was added to mWater

- datasets:

  Dataset in mWater that point is part of, including organizaiton that
  is responsible for data

- geometry:

  Geospatial data of the different access points that were added to
  mWater
